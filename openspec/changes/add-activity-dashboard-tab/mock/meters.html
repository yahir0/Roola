CPU CORES

LEVEL（放送用レベルゲージ）

  • 40 セグメントの縦 LED。0–70% 緑 / 70–90% 琥珀 / 90%+ 赤
  • 上昇は約 50ms で即応、下降は毎秒 60% ぶんずつ落ちる（PPM 風）
  • ピークホールド: 最大値を 1.5 秒保持してから落下
  • 受信/送信・読み/書きはステレオの L/R のように 2 本で対に
  • I/O は対数目盛り 1K〜1G B/s、LOAD はコア数を満点

TACHO（3 案から選択）

  • A · CLASSIC 黒い文字盤に白い目盛り、細い赤橙の針、赤いレッドゾーン。数値は針の通らない下部に大きく
  • B · DIGITAL 80–90 年代国産車のオレンジ蛍光表示管風。細かいセグメントの円弧が伸び、消灯部分もうっすら見える。通過した目盛りと数字だけ点灯
  • C · RACE GR86 / BRZ の Track Mode 風。中央に右肩上がりの CPU バーグラフ（0–4 を詰めた非線形目盛り、7 から橙・8.5 から赤）、左にメモリ / スワップの横バー、右にロードアベレージ・時刻と I/O のブロックゲージ、下に大きな数値と赤いバッジ。上部にシフトライト
  • 目盛りは実際の値（I/O は B/s）。CPU・メモリはタコメータらしく 0–10（×10 %）目盛り。メモリの数値表示は GB
  • 文字盤は装飾なしのフラットな黒。細い外周リングだけで計測器らしさを出す
  • タコ表示を開いた瞬間に全メーターが一度フルスケールまで振り切って戻る（オープニングセレモニー）
  • どの案も 270° スイープ、ばね＋ダンパ追従（減衰比 0.7）で少しだけ行き過ぎて戻る

共通

  • 既定は CPU 全体 1 本。「全コア表示」で LEVEL はコア数ぶんのバー、TACHO はコア別の小メーターを追加
  • タブ表示中だけ 250ms でポーリングし、描画は毎フレーム補間（トップバーは従来どおり 1 秒）
  • このタブに限り Polaris の単一アクセント / 0ms 規定を適用しない
