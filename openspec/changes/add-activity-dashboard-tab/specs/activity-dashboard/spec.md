## ADDED Requirements

### Requirement: アクティビティタブを開く

アプリ SHALL ワークスペースのタブとしてアクティビティモニタ（以下アクティビティ
タブ）を開けるようにする。開く経路は、タブストリップの「+」メニュー、トップバー
のアクティビティモニタのポップオーバー内「タブで開く」、コマンド
`openActivityTab`（メニューバー・キー割り当て対象）の 3 つとする。

#### Scenario: 「+」メニューから開く

- **WHEN** ユーザーがあるペインのタブストリップの「+」から「アクティビティ
  モニタ」を選ぶ
- **THEN** そのペインにアクティビティタブが追加され、アクティブになる

#### Scenario: ポップオーバーから開く

- **WHEN** ユーザーがトップバーの CPU またはメモリのポップオーバーで「タブで開く」
  を押す
- **THEN** ポップオーバーが閉じ、アクティビティタブが右上ペインに追加されて
  アクティブになる

#### Scenario: コマンドから開く

- **WHEN** ユーザーがメニューバーまたは割り当てたショートカットで
  `openActivityTab` を実行する
- **THEN** アクティビティタブが右上ペインに追加されてアクティブになる

### Requirement: アクティビティタブは 1 つだけ

アプリ SHALL ワークスペース内のアクティビティタブを最大 1 つに保つ。既に存在する
状態で開く操作をした場合は、新規に作らず既存タブをアクティブにする。

#### Scenario: 既存タブがあるときに開く

- **WHEN** アクティビティタブが既にいずれかのペインに存在し、ユーザーがいずれかの
  経路で開く操作をする
- **THEN** 新しいタブは作られず、既存のアクティビティタブが所属ペインで
  アクティブになる

### Requirement: 表示項目

アクティビティタブ SHALL 次の項目をメーターで表示する: CPU 使用率、メモリ使用率、
スワップ使用率、ディスク読み込み / 書き込み速度（B/s）、ロードアベレージ（1 / 5 /
15 分）、ネットワーク受信 / 送信速度（B/s）。OS から取得できない項目は、その
メーター自体を表示しない。

#### Scenario: 全項目が取得できる環境

- **WHEN** macOS でアクティビティタブを表示している
- **THEN** CPU・メモリ・スワップ・ディスク読み書き・ロードアベレージ・
  ネットワーク送受信のメーターが表示される

#### Scenario: 取得できない項目がある環境

- **WHEN** Windows でアクティビティタブを表示している（ロードアベレージは
  取得できない）
- **THEN** ロードアベレージのメーターは表示されず、他の項目は表示される

#### Scenario: ネットワークが検証で不採用になった場合

- **WHEN** ネットワーク I/O の取得検証（design D8）で正しい値が得られず、
  ネットワークを本機能から外した
- **THEN** ネットワークのメーターはどのモードにも表示されない

### Requirement: CPU の全体表示とコア別表示

アクティビティタブ SHALL CPU を既定でシステム全体の 1 項目として表示する。
「全コア表示」トグルがオンのとき、全体に加えて論理コアごとの使用率メーターを
コア数ぶん表示する。

#### Scenario: 既定では全体 1 本

- **WHEN** 全コア表示がオフの状態でアクティビティタブを表示する
- **THEN** CPU はシステム全体の使用率を示すメーター 1 つだけが表示される

#### Scenario: 全コア表示をオンにする

- **WHEN** ユーザーが全コア表示トグルをオンにする
- **THEN** 論理コア数ぶんのコア別メーターが追加で表示される

#### Scenario: コア別の値が取得できない

- **WHEN** OS からコア別の CPU 値を取得できない
- **THEN** 全コア表示トグルは操作できない状態で表示され、CPU は全体 1 本のまま
  表示される

### Requirement: 表示モード LEVEL

アクティビティタブ SHALL 表示モード LEVEL で、各項目を放送用レベルゲージ風の縦
LED バーで表示する。バーは 40 セグメントで、下から 70% 未満を緑、90% 未満を琥珀、
それ以上を赤とし、消灯セグメントも薄く描く。対になる項目（メモリ / スワップ、
受信 / 送信、読み込み / 書き込み）は隣接する 2 本のバーとして並べる。I/O は
1 KB/s〜1 GB/s の対数目盛り、ロードアベレージは論理コア数を満点とする。

#### Scenario: バーが値に応じて点灯する

- **WHEN** CPU 使用率が 80% である
- **THEN** CPU バーは下から 80% の位置までセグメントが点灯し、70% 以上の部分は
  琥珀で描かれる

#### Scenario: ピークホールド

- **WHEN** ある項目の値が上昇したのち下降する
- **THEN** 最大値の位置のセグメントが 1.5 秒間点灯を保ち、その後ゆっくり下がる

#### Scenario: 上昇は速く下降はゆっくり

- **WHEN** 値が急上昇した直後に急低下する
- **THEN** バーは上昇には即座に追従し、下降は一定速度（毎秒 60% 分）でゆっくり
  下がる

### Requirement: 表示モード TACHO とスタイル

アクティビティタブ SHALL 表示モード TACHO で、各項目をタコメータで表示する。
TACHO は CLASSIC / DIGITAL / RACE 1 / RACE 2 の 4 スタイルから選べる。CLASSIC と DIGITAL は
270° スイープの円形メーターで、CPU とメモリの目盛りは 0〜10（×10 %）とし、
中央または下部に数値（CPU は %、メモリは GB）を表示する。レッドゾーンは原則
85% 以上とする。

#### Scenario: CLASSIC

- **WHEN** TACHO の CLASSIC スタイルを選ぶ
- **THEN** 黒い文字盤に白い目盛りと数字、赤橙の針、赤いレッドゾーンの円形メーター
  で各項目が表示され、針は値に追従して回転する

#### Scenario: DIGITAL

- **WHEN** TACHO の DIGITAL スタイルを選ぶ
- **THEN** オレンジの蛍光表示管風のセグメント円弧で各項目が表示され、値までの
  セグメントと通過した目盛り・数字だけが点灯し、レッドゾーンに入った部分は赤橙に
  なる

#### Scenario: RACE 2

- **WHEN** TACHO の RACE 2 スタイルを選ぶ
- **THEN** 1 枚のクラスタ表示になり、中央に CPU の右肩上がりバーグラフ（GR86 /
  BRZ の Track Mode 風。低い値を詰めた非線形目盛り、70% から橙・85% から赤）、
  左にメモリとスワップの横バー、右にロードアベレージ・時刻と I/O のブロック
  ゲージ、下部に CPU の数値が表示される

#### Scenario: RACE 1

- **WHEN** TACHO の RACE 1 スタイルを選ぶ
- **THEN** RACE 2 と同じクラスタ（外枠・左右のパネル・シフトライト・コア別表示）
  で、中央の CPU 表示だけが GR86 / BRZ の通常モード風の丸型タコになる。タコは
  外枠の円の内側に収まり、0 が真下から時計回り 270° の目盛りの内側を帯が CPU の
  位置まで伸び（針は無い）、中央に CPU の数値、横線の下にロードアベレージが出る

#### Scenario: 以前の RACE の設定

- **WHEN** RACE を 2 種類に分ける前に RACE を選んで保存していた
- **THEN** RACE 2 として開く

#### Scenario: RACE のシフトライト

- **WHEN** RACE 1 / RACE 2 スタイルで CPU 使用率が 50% 以上になる
- **THEN** クラスタ上部のシフトライトが使用率に応じて左から点灯し、95% を超えると
  全灯が点滅する

### Requirement: なめらかな動き

アクティビティタブ SHALL 値の変化をなめらかなアニメーションで表示する。針・円弧・
バーはサンプル間を補間して毎フレーム動き、針は実機のようにわずかに行き過ぎて
戻る動きをする。TACHO に切り替えた直後とスタイルを変えた直後は、全メーターが
一度フルスケールまで振れてから実値に戻る。OS のアニメーション低減設定が有効な
場合は補間せず値へ即座に移る。

#### Scenario: 針が補間されて動く

- **WHEN** CPU 使用率のサンプルが 20% から 60% に変わる
- **THEN** 針は 20% から 60% へ瞬間移動せず、複数フレームかけて回転して 60% 付近で
  落ち着く

#### Scenario: オープニング演出

- **WHEN** ユーザーが表示モードを TACHO に切り替える
- **THEN** 全メーターが一度フルスケールまで振れ、約 0.5 秒後に実際の値へ戻る

#### Scenario: アニメーション低減設定

- **WHEN** OS のアニメーション低減設定が有効である
- **THEN** メーターは補間やオープニング演出を行わず、サンプル値をそのまま表示する

### Requirement: 表示中だけのポーリング

アクティビティタブ SHALL 自身が所属ペインのアクティブタブとして表示されている間
だけ、250ms 間隔でシステムメトリクスを取得する。非表示の間（ペイン内の別タブが
アクティブ、またはタブが閉じられた）は取得を止める。トップバーのアクティビティ
モニタの取得間隔（1 秒）と表示値には影響を与えない。

#### Scenario: 表示中は 250ms ごとに更新される

- **WHEN** アクティビティタブがアクティブに表示されている
- **THEN** メトリクスは 250ms ごとに取得され、メーターの目標値が更新される

#### Scenario: 別タブに切り替えると取得を止める

- **WHEN** 同じペインで別のタブをアクティブにする
- **THEN** アクティビティタブのメトリクス取得は停止する

#### Scenario: トップバーの値に影響しない

- **WHEN** アクティビティタブが 250ms 間隔で取得している
- **THEN** トップバーの CPU / メモリ表示は従来どおり 1 秒間隔で、アクティビティ
  タブが無いときと同じ算出区間の値を表示する

#### Scenario: 取得に失敗する

- **WHEN** あるポーリングでメトリクス取得が失敗する
- **THEN** アプリはクラッシュせず、メーターは直近の値を保ち、次回のポーリングで
  回復を試みる

### Requirement: 表示設定の保存

アプリ SHALL 表示モード（LEVEL / TACHO）、TACHO スタイル（CLASSIC / DIGITAL /
RACE）、全コア表示のオン / オフを保存し、次にアクティビティタブを開いたとき
（アプリ再起動後を含む）に同じ設定で表示する。未保存時の既定は LEVEL・CLASSIC・
全コア表示オフとする。

#### Scenario: 設定が再起動後も残る

- **WHEN** ユーザーが TACHO / RACE 2 / 全コア表示オンにしてアプリを再起動し、
  アクティビティタブを開く
- **THEN** TACHO の RACE 2 スタイルで、全コア表示がオンの状態で表示される

#### Scenario: 初回は既定値

- **WHEN** 表示設定を一度も変更していない状態でアクティビティタブを開く
- **THEN** LEVEL モードで、全コア表示オフの状態で表示される
